# lore/

Small, single-topic files. Read **on demand only** — never loaded wholesale.

Suggested shape:

```
floor-01.md          mechanics, hazards, factions, exit condition — one page
floor-02.md
loot-boxes.md        tiers, timing, what's in them
sponsors.md          how offers work, what strings look like
safe-rooms.md
system-shop.md
factions/goblins.md  facts only — stance lives in ../VOICE.md
```

## Two rules

1. **One page each.** If a file is longer than a page, it is doing two jobs. Split it.
2. **Facts here, stance in `VOICE.md`.** "Goblins staff the floor-1 workshops" is a fact.
   "Goblins know it's a show and will negotiate" is stance. Stance is what makes a scene
   feel right, and it needs to be in the always-loaded file.

## What not to do

Do not attempt a complete lore bible. Completeness is unreachable, it slows every response,
it eats the context that state needs, and it was never the thing that was broken. One page
for the floor you're on beats forty pages for all of them.
