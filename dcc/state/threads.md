# Open Threads

This file is why the story feels like a story instead of a series of rooms.

Every thread has **heat**: how close it is to demanding attention.
- `cold` — dormant, available if convenient
- `warm` — should resurface within a few turns
- `hot` — resurfaces **now**, at the next beat

Rules:
- Never carry more than ~6 open threads. Resolve or discard.
- When a `pressure` or `spectacle` beat fires and a `hot` thread exists, **use the thread**
  instead of inventing something new. Callbacks beat novelty.
- Anything the player is owed or owes goes here, always.
