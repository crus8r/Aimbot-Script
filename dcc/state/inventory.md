# Inventory

## Rules for maintaining this file

The failure mode is a thousand itemized lines of goblin ear. These rules prevent it.

1. **Bucket, don't itemize.** Everything lands in one of the buckets below.
2. **Bulk loot is one line with a count.** `Goblin shortswords ×412 — stash F1-S7`.
   Never enumerate identical items.
3. **Junk is a single aggregate line with an estimated sale value.** Do not track it
   individually. `Assorted scrap — ~340g if sold`.
4. **Off-body stash is real.** The player can designate a stash location. Bulk goes there.
   Carried weight only counts what's on the body.
5. **The DM writes to this file.** The player never has to ask "did that get added?" —
   anything looted, crafted, or granted is written the same turn.
6. **Nothing silently disappears.** Consumption is narrated. If it's gone, the turn text
   says why.
